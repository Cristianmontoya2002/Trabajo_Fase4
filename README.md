Sistema Integral de Gestión de Software FJ

Descripción

Aplicación de escritorio desarrollada en Python para gestionar clientes, servicios y reservas mediante una interfaz gráfica con Tkinter.

Archivos del proyecto

modelos.py: contiene las clases, excepciones y modelos del sistema.

gestion.py: contiene las operaciones de gestión de clientes, servicios y reservas.

interfaz.py: contiene la interfaz gráfica del sistema.

Requisitos

Python 3.10 o superior.

Biblioteca Tkinter.

Instrucciones de ejecución

Descargar los tres archivos del proyecto.

Guardarlos en una misma carpeta.

Abrir la carpeta desde Visual Studio Code.

Abrir una terminal.

Ejecutar el siguiente comando: python interfaz.py

Esperar a que se abra la ventana principal del sistema.
